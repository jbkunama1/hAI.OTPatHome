hAI.OTPatHome 🔐

Self‑hosted TOTP‑Server auf Basis von 2FAuth – OTP‑Codes sicher im eigenen Heimnetz.

Docker Portainer Stack 2FAuth Self‑Hosted OTP

🚀 Was ist hAI.OTPatHome?

hAI.OTPatHome ist ein leichtgewichtiges Setup, um TOTP‑Codes im eigenen Netzwerk zu hosten – als Alternative zu Handy‑Authenticator‑Apps. Die Codes liegen dabei auf deinem Server und sind über eine moderne Web‑UI erreichbar.

Im Kern läuft die Open‑Source‑App 2FAuth in einem Docker‑Container; verwaltet wird alles bequem als Portainer‑Stack.

✨ Features

  • 🔑 Self‑hosted TOTP für deine Logins
  • 🌐 Zugriff im LAN und optional per Domain von außen
  • 📦 Einfache Bereitstellung via Docker / Portainer
  • 🧠 Verständliche Konfiguration & ENV‑Variablen
⭐ Projekt auf GitHub 📘 README ansehen

⚙️ Stack‑Snippet

Minimaler Docker‑Stack für Portainer – Port 4444 nach außen, SQLite‑Datenbank im Volume:

services:
  2fauth:
    image: 2fauth/2fauth:latest
    container_name: 2fauth
    restart: unless-stopped
    ports:
      - "4444:8000"
    volumes:
      - /opt/docker/2fauth:/2fauth
    environment:
      APP_NAME: "2FAuth"
      APP_ENV: "production"
      APP_DEBUG: "false"
      APP_URL: "http://DEINE-IP:4444"
      APP_KEY: "base64:DEIN_APP_KEY"
      APP_TIMEZONE: "Europe/Berlin"
      DB_CONNECTION: "sqlite"
      DB_DATABASE: "/2fauth/database/database.sqlite"
⚠️ DB-Pfad: Die SQLite-Datei liegt im Unterordner /database/:
DB_DATABASE: "/2fauth/database/database.sqlite"

🔑 APP_KEY muss mit base64: beginnen. Generieren mit:
docker exec -it 2fauth php artisan key:generate --show

💡 APP_URL immer auf die echte IP/Domain setzen (kein Trailing-Slash).
